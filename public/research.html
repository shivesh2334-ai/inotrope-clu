Research Hub

Collect vasoactive registry rows into a Google Sheet via a Google Apps Script Web App, proxied server-side to avoid CORS.

Setup (one-time)

The Research Hub submits rows through POST /api/research/submit, which forwards them to your own deployed Apps Script Web App. This app can never be hosted "inside" this Vercel deployment — Apps Script is a separate Google Workspace deployment target (script.google.com) by design.

  1. Open script.google.com and create a new standalone project.
  2. Paste the contents of google-apps-script/sheet-provisioner.gs into the editor.
  3. Deploy → New deployment → Type: Web App, Execute as: Me, Who has access: Anyone with the link (or your Workspace domain).
  4. Copy the Web App URL (ends in /exec).
  5. Set it as the APPS_SCRIPT_URL environment variable in your deployment (Vercel: Project Settings → Environment Variables), then redeploy.

Until this is configured, submissions below will return a 501 with a message explaining what's missing — that's expected, not a bug.
